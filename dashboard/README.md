# PTCG Meta Backtest Explorer

`index.html` is a self-contained interactive snapshot generated by `scripts/build_dashboard.py` from the historical research archive.

Current views:

- Overview of Online/IRL coverage by legal format
- Filterable IRL major list
- Per-major prediction-window audit
- Actual Day-1 field
- Compatible Online tournament evidence and raw aggregated field
- Prior same-format and previous-format IRL evidence
- Raw Online-vs-actual archetype comparison
- Historical set/rotation legality timeline
- Data-quality thresholds and modelling assumptions

The dashboard deliberately exposes evidence before model fitting. Baseline and fitted backtest results can be added to the same explorer once generated.
